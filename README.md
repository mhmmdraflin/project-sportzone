# 🏟️ SPORTZONE - Aplikasi Pemesanan Lapangan Olahraga

**SPORTZONE** adalah aplikasi Android yang memudahkan pengguna untuk melakukan pemesanan lapangan olahraga secara online. Dengan antarmuka yang ramah pengguna dan fitur lengkap, SPORTZONE memungkinkan pengguna memilih jadwal, lapangan, serta melakukan pembayaran digital dengan mudah.

---

## 📱 Fitur Utama

- ✅ **Splash Screen**  
  Menampilkan logo aplikasi saat awal dibuka untuk meningkatkan branding dan profesionalisme.

- ✅ **Login Screen**  
  Form login sederhana untuk mengamankan akses pengguna ke dalam aplikasi.

- ✅ **Formulir Booking Lapangan**  
  Pengguna dapat melakukan pemesanan dengan mengisi:  
  - Nama  
  - Nomor HP  
  - Tanggal booking  
  - Pilihan jenis lapangan (Futsal, Badminton, Basket, dll)  
  - Pilihan waktu/jam main  

- ✅ **Metode Pembayaran Digital (Simulasi)**  
  Mendukung pilihan pembayaran:  
  - 🟣 GoPay  
  - 🟦 Dana  
  - 🟡 OVO  

- ✅ **Riwayat Booking**  
  Menampilkan histori pemesanan yang tersimpan secara lokal di database SQLite.
